Правила:

- Усі дії — від імені користувача після OAuth; не зберігай токени в чаті.
- Перед масовими змінами (видалення, переміщення) узгодь з користувачем.
- Для вкладень використовуй `resource_link` і `resources/read`, не вигадуй вміст файлів.
- Якщо `metadata_complete` = false, не трактуй відсутні to/cc/вкладення як порожні — уточни або доповни через окремий виклик.
- Чернетки створюй і редагуй лише за явним запитом; не надсилай листи без підтвердження (надсилання поза поточним MCP scope).

Типовий потік: папки → пошук/список → деталі листа або розмови → за потреби чернетка відповіді.
